# Typography

## Primary recommendation

Use **Manrope** as the primary Lowcountry Digital Works interface and website family.

Recommended stack:

```css
font-family: "Manrope", "Source Sans 3", Inter, system-ui, -apple-system,
  BlinkMacSystemFont, "Segoe UI", sans-serif;
```

Suggested weights:

- Display / H1 / H2: 700
- H3 / H4 / navigation / buttons: 600–650
- Body: 400–500

## Logo lockup note

The production standalone mark is completely font-independent.

For portability, the supplied horizontal and stacked SVG lockups contain outlined wordmark paths. The paths were produced from Inter as a close self-contained match to the approved generated reference; the normal LDW website and application typography remains Manrope-led.
