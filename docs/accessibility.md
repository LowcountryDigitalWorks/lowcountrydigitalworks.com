# Accessibility

The website targets WCAG 2.2 Level AA where applicable.

Required practices include:

- semantic landmarks and heading order;
- keyboard-operable navigation and controls;
- visible focus states;
- sufficient color contrast;
- descriptive link text;
- text alternatives for meaningful images;
- responsive reflow without horizontal scrolling at common viewport sizes;
- reduced-motion support;
- no interaction that depends only on color, hover, or precise pointer control.

Automated checks support but do not replace keyboard and visual review.
