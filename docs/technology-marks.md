# Technology mark usage

Release 0.5 uses locally stored monochrome SVG marks to identify technologies currently used in Lowcountry Digital Works website, application, automation, and delivery work.

## Source

The SVG artwork under `public/technology/` is derived from the Simple Icons project (`simple-icons/simple-icons`). Simple Icons publishes its icon artwork under CC0 1.0 Universal.

## Trademark boundary

CC0 does not grant trademark rights. Product names and marks remain the property of their respective owners and are used only for descriptive identification. Their appearance on the Lowcountry Digital Works website does not imply sponsorship, certification, partnership, or endorsement.

## Runtime/privacy boundary

The marks are committed to this repository and served from the Lowcountry Digital Works origin. The website does not load the images from Simple Icons, vendor CDNs, or other third-party runtime services.

## Current marks

- GitHub
- Cloudflare
- Astro
- TypeScript
- Python

Add a new mark only when Lowcountry Digital Works can truthfully say the technology is used in current work and the licensing/trademark boundary has been reviewed.
