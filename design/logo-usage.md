# Logo Usage — Production UX Guidance

## Authoritative identity

The selected and production-ready direction is **Image 1 / Tidal Framework**. Production Brand Package v2 is final and authoritative.

The canonical mark uses:
- Estuary Navy `LD`;
- Cypress Teal `W` / tidal flow;
- outlined production wordmark geometry in the lockups;
- dedicated monochrome and white/inverse treatments.

Historical raster concept references remain reference-only in the retained production package and must not be used as runtime or production masters.

## Canonical website assets

- light header: `brand/logo/lowcountry-digital-works-logo-horizontal.svg`
- dark/navy footer: `brand/logo/lowcountry-digital-works-logo-horizontal-white.svg`
- standalone mark: `brand/logo/lowcountry-digital-works-mark.svg`
- favicon: `brand/icons/favicon.svg` with ICO/PNG fallbacks
- Apple touch icon: `brand/icons/apple-touch-icon.png`
- social preview: `brand/social/social-card-1200x630.png`

The `horizontal-light.svg` and `horizontal-dark.svg` files are convenience aliases, not separate visual masters.

## Clear space and minimum sizes

Use the production brand guide as authority:
- standalone mark: `1× X` clear space;
- horizontal/stacked lockups: `0.75× X`;
- normal digital mark: 24px minimum;
- optical favicon: 16px allowed;
- horizontal lockup: 180px minimum;
- stacked lockup: 110px minimum.

## Typography relationship

The fixed outlined wordmark geometry is part of the logo artwork. Website/application typography remains Manrope-led with Source Sans 3 and Inter/system fallbacks. Do not substitute live Inter text for the outlined wordmark and do not change UI typography merely to match the logo paths.

## Decorative use

Do **not** alter the production mark with opacity, transparency, gradients, glow, shadows, texture, or separate LD/W opacity values. The earlier translucent watermark treatment is retired.

If a branded background pattern is wanted later, create a separately approved pattern asset rather than modifying the production logo.

## App/avatar contexts

Use the supplied square light/dark app or social-avatar assets when a square container is genuinely required. Do not place the normal logo into a new rounded-square treatment or invent a separate mark.
